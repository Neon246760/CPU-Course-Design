# 附加功能设计与测试

## 1. 实现范围

| 功能 | 实现 |
|---|---|
| 溢出判断 | `ADD/SUB/ADDI` 在 EX 级检测 32 位有符号溢出；溢出指令不提交 |
| 中断/异常 | 外部中断双触发同步、pending、MIE/MPIE、`mtvec/mepc/mcause`、`MRET` |
| I-Cache | 1 KiB、直接映射、16 B 行、4 字整行填充 |
| D-Cache | 1 KiB、直接映射、16 B 行、写直达、写不分配、MMIO bypass |
| 分支预测 | 16 项 BTB + 16 个 2 位饱和计数器，初始弱不跳转 |

SoC 参数 `ENABLE_ICACHE`、`ENABLE_DCACHE`、`ENABLE_BRANCH_PREDICTION` 可分别关闭功能，便于基线回归和性能对比。

## 2. 溢出与异常语义

加法和减法检测式为：

```text
overflow_add = ~(a31 ^ b31) & (result31 ^ a31)
overflow_sub =  (a31 ^ b31) & (result31 ^ a31)
```

课程设计规定 `ADD/SUB/ADDI` 溢出时触发异常，原因码为 16。该规定不同于标准 RV32I 的模 2^32 加减语义，报告中必须明确。

异常在 EX 级确认，故障指令不会进入 EX/MEM，IF/ID 和 ID/EX 中更年轻指令全部作废。为使当前没有 CSR 写指令的最小处理程序可以直接 `MRET`，本实现将 `mepc` 保存为故障指令的 `PC+4`。这也是课程化约定，不应表述为完整特权规范实现。

非法指令原因码为 2，`ECALL` 原因码为 11。异常入口默认为 `mtvec=0x0000_0100`。

## 3. 外部中断

`ext_irq` 经两级触发器同步并锁存 pending。复位后 MIE 默认开启；进入异常或中断时把 MIE 保存到 MPIE 并关闭 MIE，`MRET` 恢复。

中断只在安全 EX 边界接受：当前 EX 指令必须为空或为非控制、非系统普通指令。该指令允许继续完成，年轻指令被冲刷，`mepc` 保存下一条应执行的 PC。若 D-Cache/数据总线正在等待，中断保持 pending，待旧访存完成后再接受。

中断 `mcause=0x8000_000B`。优先顺序为：

```text
旧访存完成约束 → 同步异常 → MRET → 外部中断 → 分支误预测 → load-use → 正常推进
```

同步异常在体系结构意义上高于中断；旧访存等待用于保证更老指令先完成。

## 4. Cache

地址拆分（64 行、16 B/行）：

| 字段 | 位段 |
|---|---|
| offset | `[3:0]` |
| index | `[9:4]` |
| tag | `[31:10]` |

I-Cache miss 后按 4 个 32 位字依次填充整行。若填充期间发生异常、中断或误预测，已发起填充可以完成，但只有请求地址仍与当前 PC 相同时才向 CPU 返回响应，避免错误路径指令进入流水线。

D-Cache 对 `0x1000_0000～0x1000_FFFF` 缓存。store 命中时同时更新 Cache 行并写入下层存储器；store miss 直接写下层但不分配。MMIO 和保留地址直接旁路，不计入 D-Cache 命中率。

## 5. 分支预测

IF 级使用 PC 同时查询 BTB 和 BHT。BTB tag 命中且计数器高位为 1 时预测跳转。预测方向和目标随 IF/ID、ID/EX 传递；EX 级比较实际下一 PC 与预测下一 PC。

确认的 branch、JAL、JALR 只更新一次。被更老访存冻结或被异常取消的指令不更新预测器。计数器状态为：

```text
00 强不跳转 → 01 弱不跳转 → 10 弱跳转 → 11 强跳转
```

## 6. 自检测试矩阵

| testbench | 覆盖内容 | 通过标准 |
|---|---|---|
| `tb_alu_overflow` | 正/负加减溢出、不误报、全部 ALU 操作 | 每个结果和 overflow 位自动比较 |
| `tb_decode_microcode` | 27 条基础指令 + ECALL/MRET + 非法指令 | 微地址、源寄存器使用、系统/溢出控制正确 |
| `tb_branch_predictor` | 冷启动、taken/not-taken 训练、饱和、BTB tag 冲突 | 预测方向和目标逐步自检 |
| `tb_cache` | 冷 miss、同行 hit、同 index 替换、写直达、写不分配、字节写、MMIO bypass | 数据与 hit/miss 数自检 |
| `tb_cpu_core` | 基础流水回归、双源前递、load-use、branch/JAL 冲刷、SB/LBU | 寄存器、存储器、计数器自检 |
| `tb_extended_system` | 溢出异常、MRET、中断、Cache miss 期间 pending、循环预测、错误路径溢出抑制 | 架构状态、CSR、Cache/预测统计自检 |

## 7. Vivado 2019.2 实测结果

| testbench | 结果 | 关键数据 |
|---|---|---|
| `tb_alu_overflow` | PASS | 全部边界和 ALU 用例通过 |
| `tb_decode_microcode` | PASS | 29 条有效编码和非法编码通过 |
| `tb_branch_predictor` | PASS | 训练、饱和、tag 冲突通过 |
| `tb_cache` | PASS | I$ hit/miss=`1/3`，D$ hit/miss=`3/3` |
| `tb_cpu_core` | PASS | 关闭 Cache/预测器的基础回归；cycles=`24`，instret=`15`，data stall=`1`，flush=`2` |
| `tb_extended_system` | PASS | cycles=`110`，instret=`49`，I$=`55/8`，D$=`1/2`，branch/miss=`14/5` |

系统测试还检查：故障 ADD 不写 rd；错误路径上的溢出不产生第二次异常；D-Cache miss 期间到达的中断先 pending 后响应；异常和中断处理程序各执行一次；`MRET` 返回后主程序不重复、不跳过。
