# 地址空间与 MMIO 寄存器表

## 1. 地址空间

本表冻结当前课程设计的逻辑地址。开发板配置的 IMEM/DMEM 各为 8 KiB，小于下表保留的 64 KiB 逻辑窗口；当前存储器索引只取物理容量所需的低位，因此软件必须将访问限制在实际容量内。未实现访问故障异常。

| 地址范围 | 名称 | 用途 | 属性 |
|---|---|---|---|
| `0x0000_0000`～`0x0000_FFFF` | IMEM | 64 KiB 指令空间 | 只读、仅取指 |
| `0x1000_0000`～`0x1000_FFFF` | DMEM | 64 KiB 数据 RAM | 可读写 |
| `0x2000_0000`～`0x2000_0FFF` | GPIO/UART/LCD/BUZZER | 外设 MMIO | 强顺序、不可缓存 |
| `0xFFFF_FFF0`～`0xFFFF_FFFF` | TEST | 仿真 testbench 控制 | 仅仿真使用 |
| 其他 | RESERVED | 保留 | 读返回 0，写忽略 |

复位入口 `RESET_VECTOR = 0x0000_0000`。栈顶建议设为 `0x1001_0000`，栈向低地址增长。

## 2. 基础 MMIO 寄存器

| 地址 | 名称 | 访问 | 位定义 |
|---|---|---|---|
| `0x2000_0000` | `GPIO_OUT` | RW | `[31:0]` 输出寄存器，可接 LED/数码管 |
| `0x2000_0004` | `GPIO_IN` | RO | `[31:0]` 输入同步值，可接按键/拨码开关 |
| `0x2000_0010` | `UART_TXDATA` | WO | 写 `[7:0]` 发送一个字符；忙时总线保持 `ready=0` |
| `0x2000_0014` | `UART_STATUS` | RO | bit0=`tx_ready`，其余读 0 |
| `0x2000_0020` | `LCD_CMD` | WO | 写低 8 位发送 LCD 命令 |
| `0x2000_0024` | `LCD_DATA` | WO | 写低 8 位发送 LCD 数据 |
| `0x2000_0028` | `LCD_STATUS` | RO | bit0=`tx_ready`，bit1=`initialized` |
| `0x2000_002C` | `LCD_CTRL` | WO | bit0=重新初始化，bit1=清屏，bit2=显示 `WJL ZXH QBA` 字模页 |
| `0x2000_0030` | `LCD_GAME_ROW` | WO | `[20:16]`=行号 0～19，`[9:0]`=该行 10 格占用位 |
| `0x2000_0034` | `LCD_GAME_REFRESH` | WO | 写 bit0=1 启动一次 10×20 棋盘刷新 |
| `0x2000_0038` | `BUZZER_TRIGGER` | WO | 写 bit0=1 触发一次板级蜂鸣提示音 |
| `0xFFFF_FFF0` | `TOHOST` | WO | 写 1=PASS，其他非零值=FAIL 码 |

`LCD_GAME_ROW/REFRESH` 在 LCD 忙时令总线保持 `ready=0`，避免 CPU 改写渲染器正在读取的
20×10 位行缓冲。`BUZZER_TRIGGER` 产生单周期触发，板级逻辑将其扩展为约 2 kHz、120 ms
的方波。外部中断经 CPU 独立的 `ext_irq` 端口进入，不经 MMIO 中断控制器。
性能计数器已作为 SoC 调试输出实现，但尚未映射为 MMIO；当前也没有定时器外设。

## 3. 数据存储器接口

| 信号 | 方向 | 位宽 | 说明 |
|---|---|---:|---|
| `req` | CPU→存储系统 | 1 | 请求有效；等待期间保持 |
| `addr` | CPU→存储系统 | 32 | 字节地址 |
| `write` | CPU→存储系统 | 1 | 1=写，0=读 |
| `wdata` | CPU→存储系统 | 32 | 已按地址低位对齐的写数据 |
| `wstrb` | CPU→存储系统 | 4 | 每位对应一个字节通道 |
| `ready` | 存储系统→CPU | 1 | 当前请求完成 |
| `rdata` | 存储系统→CPU | 32 | 读数据所在的对齐字 |

请求方必须从 `req=1` 起到 `ready=1` 的采样沿保持 `addr/write/wdata/wstrb` 不变。一次请求只允许产生一次副作用。

## 4. 字节通道

| 指令/addr[1:0] | wstrb | wdata |
|---|---|---|
| SW / `00` | `1111` | `rs2` |
| SB / `00` | `0001` | `{24'b0,rs2[7:0]}` |
| SB / `01` | `0010` | `{16'b0,rs2[7:0],8'b0}` |
| SB / `10` | `0100` | `{8'b0,rs2[7:0],16'b0}` |
| SB / `11` | `1000` | `{rs2[7:0],24'b0}` |

加载时先用 `addr[1:0]` 选择 `rdata` 中对应字节，再由 `load_unsigned` 决定零扩展或符号扩展。
