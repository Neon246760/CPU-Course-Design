# 流水寄存器字段表

## 1. 通用规则

- 每组流水寄存器均有 `valid` 位；复位或冲刷时置 0。
- `enable=0` 时保持全部字段；插入气泡时仅需将目标级 `valid` 清零。
- 只有 `valid=1` 的指令才允许产生寄存器写、存储器写、分支重定向和退休事件。
- 数据字段复位值不影响功能，建议置 0 便于观察波形。

## 2. IF/ID

| 字段 | 位宽 | 来源 | 用途 |
|---|---:|---|---|
| `valid` | 1 | IF | 指令有效标志 |
| `pc` | 32 | PC | 译码、分支目标、调试 |
| `pc_plus4` | 32 | IF 加法器 | 跳转链接值 |
| `instr` | 32 | 指令存储器 | ID 译码 |

控制：正常推进时写入；`imem_wait` 或 load-use 时保持；`redirect` 时清零。

## 3. ID/EX

| 字段 | 位宽 | 来源 | 用途 |
|---|---:|---|---|
| `valid` | 1 | IF/ID | EX 有效标志 |
| `pc` | 32 | IF/ID | 分支/JAL/AUIPC |
| `pc_plus4` | 32 | IF/ID | JAL/JALR 写回 |
| `instr` | 32 | IF/ID | 调试/退休追踪 |
| `rs1_idx` | 5 | 译码 | 前递比较 |
| `rs2_idx` | 5 | 译码 | 前递比较 |
| `rd_idx` | 5 | 译码 | 目的寄存器 |
| `rs1_value` | 32 | 寄存器堆 | EX 操作数候选 |
| `rs2_value` | 32 | 寄存器堆 | EX 操作数及 store 数据候选 |
| `imm` | 32 | 立即数生成器 | EX 操作数/目标偏移 |
| `uses_rs1` | 1 | 译码 | 冒险检测有效条件 |
| `uses_rs2` | 1 | 译码 | 冒险检测有效条件 |
| `alu_op` | 4 | 微码 | ALU 控制 |
| `op_a_sel` | 2 | 微码 | ALU A 选择 |
| `op_b_sel` | 2 | 微码 | ALU B 选择 |
| `reg_write` | 1 | 微码 | 向后传递 |
| `wb_sel` | 2 | 微码 | 向后传递 |
| `mem_read` | 1 | 微码 | 向后传递/冒险检测 |
| `mem_write` | 1 | 微码 | 向后传递 |
| `mem_size` | 2 | 微码 | 向后传递 |
| `load_unsigned` | 1 | 微码 | 向后传递 |
| `branch_type` | 3 | 微码 | EX 分支比较 |
| `jump_type` | 2 | 微码 | EX 跳转控制 |

控制：正常推进时写入；后端存储器等待时保持；load-use 时清 `valid` 以插入气泡；`redirect` 时清零。

## 4. EX/MEM

| 字段 | 位宽 | 来源 | 用途 |
|---|---:|---|---|
| `valid` | 1 | ID/EX | MEM 有效标志 |
| `pc` | 32 | ID/EX | 调试/退休追踪 |
| `instr` | 32 | ID/EX | 调试/退休追踪 |
| `rd_idx` | 5 | ID/EX | 前递和写回 |
| `alu_result` | 32 | ALU | 算术结果或访存地址 |
| `store_data` | 32 | 前递后的 rs2 | 存储写数据 |
| `pc_plus4` | 32 | ID/EX | JAL/JALR 写回 |
| `reg_write` | 1 | ID/EX | 向后传递/前递判定 |
| `wb_sel` | 2 | ID/EX | 向后传递 |
| `mem_read` | 1 | ID/EX | 发起读请求 |
| `mem_write` | 1 | ID/EX | 发起写请求 |
| `mem_size` | 2 | ID/EX | 字节使能/加载选择 |
| `load_unsigned` | 1 | ID/EX | 加载扩展 |

控制：数据存储器请求未完成时保持；已接受的分支重定向不会清除 EX/MEM，因为产生重定向的指令本身必须继续完成。

## 5. MEM/WB

| 字段 | 位宽 | 来源 | 用途 |
|---|---:|---|---|
| `valid` | 1 | EX/MEM | WB 有效标志 |
| `pc` | 32 | EX/MEM | 退休追踪 |
| `instr` | 32 | EX/MEM | 退休追踪 |
| `rd_idx` | 5 | EX/MEM | 寄存器写地址 |
| `alu_result` | 32 | EX/MEM | ALU 类写回 |
| `load_data` | 32 | 加载/存储单元 | load 类写回 |
| `pc_plus4` | 32 | EX/MEM | JAL/JALR 写回 |
| `reg_write` | 1 | EX/MEM | 写使能 |
| `wb_sel` | 2 | EX/MEM | 写回选择 |

控制：正常情况下每周期推进；数据存储器等待导致 EX/MEM 保持时，MEM/WB 应注入气泡，避免同一条旧指令重复退休。

## 6. 写回与退休条件

```text
rf_we  = mem_wb.valid && mem_wb.reg_write && (mem_wb.rd_idx != 0)
retire = mem_wb.valid
```

存储指令以数据存储器完成握手的周期视为体系结构提交，但统一退休计数仍在其进入 WB 后执行一次。
