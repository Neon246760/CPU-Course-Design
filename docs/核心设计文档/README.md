# 核心功能设计文档索引

本文档集依据 `docs/设计方案.md` 生成，作为基础五级流水 CPU 开发前的接口契约。

## 设计基线

- 32 位 RV32I 教学子集，共 27 条指令；
- 五级流水：IF、ID、EX、MEM、WB；
- ID 级查询微程序 ROM，一条基础指令对应一条水平型微指令；
- Harvard 接口，指令存储器与数据存储器分离；
- 数据相关由 EX/MEM、MEM/WB 前递和 load-use 停顿解决；
- 分支和跳转在 EX 级确定，默认静态“不跳转”；
- 存储器采用 `req/ready` 握手，可插入等待周期。

## 基线文档的原始范围

- 算术溢出判断及溢出异常；
- 中断、CSR、`ECALL`、`MRET`；
- I-Cache、D-Cache 及 Cache miss；
- BTB、BHT 等动态分支预测。

以上四项后来已经实现。其升级后接口、语义和测试结果统一记录在
[附加功能设计与测试](../附加功能设计与测试.md)；本目录继续保留为关闭附加功能时的基础接口契约。
