# 核心功能测试用例清单

所有 testbench 应自检最终寄存器、存储器、退休次数与 `TOHOST`，并设置最大周期超时。附加功能相关测试不在本清单内。

## 1. 模块级测试

| ID | 模块 | 用例 | 关键检查 |
|---|---|---|---|
| U-ALU-01 | ALU | ADD/SUB 普通值、0、全 1 | 低 32 位结果正确 |
| U-ALU-02 | ALU | AND/OR/XOR 固定位型 | 每位逻辑正确 |
| U-ALU-03 | ALU | SLL/SRL/SRA，移位量 0/1/31/大于31 | 仅使用低 5 位，符号填充正确 |
| U-ALU-04 | ALU | SLT/SLTU 边界 | 有符号与无符号结果不同且正确 |
| U-IMM-01 | imm_gen | I/S/B/U/J 正负立即数 | 拼接、符号扩展、最低位补 0 正确 |
| U-RF-01 | regfile | 双读单写、同周期读写 | 写回与旁路约定一致 |
| U-RF-02 | regfile | 尝试写 x0 | x0 始终为 0 |
| U-DEC-01 | decoder/uROM | 27 条合法指令 | uaddr 和全部控制字段与规格表一致 |
| U-DEC-02 | decoder/uROM | 未支持编码 | 无寄存器/存储器副作用，illegal 置位 |
| U-FWD-01 | forwarding | EX/MEM 与 MEM/WB 同时匹配 | EX/MEM 优先 |
| U-FWD-02 | forwarding | rd=x0 或 reg_write=0 | 不前递 |
| U-HAZ-01 | hazard | load-use 各源组合 | 只对真实使用的源寄存器停顿 |
| U-LSU-01 | LSU | LB/LBU 四个字节位置 | 选择及符号/零扩展正确 |
| U-LSU-02 | LSU | SB 四个字节位置、SW | `wstrb/wdata` 正确 |

## 2. 指令级测试

| ID | 范围 | 测试要点 |
|---|---|---|
| I-ALU-R | 10 条 R 型 ALU | 正数、负数、零、边界位型，结果写入普通 rd 与 x0 |
| I-ALU-I | ADDI/ANDI/ORI/XORI | 正负立即数、12 位边界 `0x7FF/0x800` |
| I-LOAD | LW/LB/LBU | 地址偏移、四个字节位置、符号扩展差异 |
| I-STORE | SW/SB | 写后读回，验证相邻字节未被破坏 |
| I-BR | BEQ/BNE/BLT/BGE | taken/not-taken、正负比较、前向/后向偏移 |
| I-JUMP | JAL/JALR | 目标与 `rd=PC+4`；JALR bit0 清零 |
| I-UPPER | LUI/AUIPC | 高位构造和 PC 相对结果 |

## 3. 流水线相关测试

| ID | 指令模式 | 期望 |
|---|---|---|
| H-RAW-01 | `ADD x1,...; SUB ...,x1,...` | EX/MEM→EX 前递，无停顿 |
| H-RAW-02 | 生产者与消费者间隔一条指令 | MEM/WB→EX 前递，无停顿 |
| H-RAW-03 | 连续两次写同一 rd 后读取 | 使用最近的 EX/MEM 值 |
| H-LOAD-01 | `LW x1,...; ADD ...,x1,...` | 恰好一个基础停顿，结果正确 |
| H-LOAD-02 | `LW x1,...; SW x1,...` | store 数据依赖被停顿/前递正确处理 |
| H-STORE-01 | ALU 结果立即作为 store 地址 | 地址源前递正确 |
| H-STORE-02 | ALU 结果立即作为 store 数据 | store-data 前递正确 |
| H-X0-01 | 前序指令 rd=x0，后序读取 x0 | 不误前递、不误停顿 |

## 4. 控制流测试

| ID | 场景 | 期望 |
|---|---|---|
| C-BR-01 | 分支不跳转 | 无冲刷，顺序指令均退休 |
| C-BR-02 | 分支跳转 | IF/ID、ID/EX 两条错误路径指令不产生副作用 |
| C-BR-03 | 分支依赖前一条 ALU 结果 | 比较使用前递值 |
| C-BR-04 | 分支依赖前一条 load 结果 | load-use 停顿后比较正确 |
| C-JAL-01 | JAL 后错误路径含寄存器写和 SW | 两种副作用均被禁止，链接值正确 |
| C-JALR-01 | JALR 基址来自前序 ALU | 目标使用前递值，bit0 清零 |
| C-LOOP-01 | 多次循环后退出 | 迭代次数、退休序列和最终结果正确 |

## 5. 存储器等待与系统测试

| ID | 场景 | 期望 |
|---|---|---|
| M-WAIT-01 | 指令存储器随机等待 0～3 周期 | 指令不丢失、不重复发射 |
| M-WAIT-02 | 数据读随机等待 0～5 周期 | 后端状态保持，load 只写回一次 |
| M-WAIT-03 | 数据写随机等待 0～5 周期 | store 只提交一次 |
| M-MMIO-01 | GPIO_OUT 写入后读回 | 寄存器值与字节写规则正确 |
| M-UART-01 | UART busy 时写 TXDATA | 请求保持到 ready，字符只发送一次 |
| S-PROG-01 | 数组求和 | load、循环、相关处理和最终和正确 |
| S-PROG-02 | 内存复制 | load/store 数据与地址依赖正确 |
| S-PROG-03 | 函数调用 | JAL/JALR、栈和返回地址正确 |
| S-PROG-04 | 冒泡排序小数组 | 综合控制流与访存结果正确 |

## 6. 统一通过标准

- 所有用例在约定最大周期内写 `TOHOST=1`；
- 不得出现向 `x0` 写入后读出非零；
- 退休 PC/指令不得重复或遗漏；
- 被冲刷指令不得写寄存器、数据存储器或 MMIO；
- 改变指令/数据存储器等待周期后，架构结果保持一致；
- 波形至少保存 load-use、双源前递、taken branch 冲刷、数据存储器等待四类证据。
